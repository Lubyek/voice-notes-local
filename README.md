# Тестовый звонок PeopleDo

[Открыть демо на GitHub Pages](https://lubyek.github.io/voice-notes-local/). Нажми «Запустить тестовый звонок», чтобы услышать русскоязычного собеседника. В конце его реплики микрофон выключится автоматически. Для своей речи используй кнопки «Включить микрофон» и «Выключить микрофон».

Во время речи браузер посылает короткие WAV-фрагменты в Grok STT 2.0 через Cloudflare Worker, по возможности отправляя их по паузам. ProxyAPI принимает аудио отдельными файлами. Как только микрофон выключается и Grok заканчивает последний фрагмент, весь текст идёт одним запросом в DeepSeek V4.1 Flash. Очищенная версия появляется по мере генерации в отдельной панели. История обеих версий хранится в браузере.

## Публикация

GitHub Pages публикует папку `/docs` из ветки `main`. Секрет `PROXYAPI_API_KEY` хранится в Cloudflare Worker. Для сборки обработчика используй `npm ci`, `npm run build` и `npx cf deploy --prebuilt --dry-run`. Для публикации войди через `npx cf auth login` и выполни `npx cf deploy --prebuilt --secrets-file <закрытый-файл>`. В `docs/service-config.js` укажи адрес Worker без пути. Worker обслуживает `/transcribe` и `/cleanup` и ограничивает запросы по IP и точке присутствия.

## Локальный Python-сервер

```bash
read -r -s -p 'Ключ ProxyAPI: ' PROXYAPI_API_KEY
export PROXYAPI_API_KEY
python app.py
```

На http://localhost:8765 доступен режим записи через Python с финальной обработкой после остановки. История этого режима хранится в SQLite.
