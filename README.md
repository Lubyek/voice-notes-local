# Тестовый звонок PeopleDo

[Открыть демо на GitHub Pages](https://lubyek.github.io/voice-notes-local/). Нажми «Запустить тестовый звонок», чтобы услышать русскоязычного собеседника. В конце его реплики микрофон выключится автоматически. Для своей речи используй кнопки «Включить микрофон» и «Выключить микрофон».

Во время речи браузер посылает короткие WAV-фрагменты в Grok STT 2.0 через Cloudflare Worker, по возможности отправляя их по паузам. ProxyAPI принимает аудио отдельными файлами. Как только микрофон выключается и Grok заканчивает последний фрагмент, весь текст идёт одним запросом в DeepSeek V4.1 Flash. Очищенная версия появляется по мере генерации в отдельной панели. История обеих версий хранится в браузере.

## Публикация

GitHub Pages публикует папку `/docs` из ветки `main`. Секрет `PROXYAPI_API_KEY` хранится в Cloudflare Worker. Для сборки обработчика используй `npm ci`, `npm run build` и `npx cf deploy --prebuilt --dry-run`. Для публикации войди через `npx cf auth login` и выполни `npx cf deploy --prebuilt --secrets-file <закрытый-файл>`. В `docs/service-config.js` укажи адрес Worker без пути. Worker обслуживает `/transcribe` и `/cleanup` и ограничивает запросы по IP и точке присутствия.

## Локальный Python-сервер

```bash
read -r -s -p 'Ключ ProxyAPI: ' PROXYAPI_API_KEY
export PROXYAPI_API_KEY
python app.py
```

На http://localhost:8765 доступен режим записи через Python с финальной обработкой после остановки. История этого режима хранится в SQLite.

## PeopleDo для Omarchy

Текущая настольная сборка рассчитана на Omarchy / Arch Linux x86_64 с PipeWire и XWayland. Распакуй `PeopleDo-0.3.0-Omarchy-x86_64.tar.zst` целиком и запусти `./PeopleDo` из распакованной папки. Electron входит в архив. Повторный запуск открывает существующее окно приложения, а закрытие окна сворачивает его в трей.

### Запись и обработка

- **Новая встреча** создаёт запись с ИИ-сводкой. **Личная запись** подходит для диктовки и коротких голосовых заметок. Обе кнопки захватывают только микрофон владельца приложения. Системный звук и видеопоток не используются.
- PipeWire позволяет предложить транскрипцию при включении микрофона в стороннем приложении. Для поддерживаемых вкладок Chromium также используется системный интерфейс доступности AT-SPI. Пауза и возобновление идут в рамках одной записи. Для быстрой встречи доступны меню трея и сочетание `Ctrl + Alt + R`, если сочетание доступно в текущей сессии.
- Grok STT через ProxyAPI распознаёт звук. DeepSeek через тот же Worker очищает текст и составляет сводку. По умолчанию распознавание идёт по ходу речи. В настройках его можно отложить до завершения записи. Исходный звук обрабатывается через API и не сохраняется в истории PeopleDo.
- Встречи сохраняются после 31 секунды. Личная запись может длиться до 15 минут, встреча до 60 минут. При сбое частичный результат сохраняется, если уже есть распознанный текст. Таймкоды показывают начало фрагмента распознавания, если провайдер не вернул детализацию.
- Сводка поддерживает краткий итог, ключевые пункты, решения и задачи с ответственными и сроками. Можно выбрать язык, изменить текст сводки или сформировать её заново. История и личные заметки хранятся в настольном профиле. Поиск охватывает заголовок, текст, сводку и заметки.

### Календарь и обмен

Доступны локальные события, импорт разовых встреч из `.ics`, напоминания за минуту, сохранение прошедшей встречи в календаре и открытие HTTPS-ссылки на звонок. Автозапуск при входе через PeopleDo включается отдельно. Повторяющиеся, отменённые и целодневные события при импорте пропускаются.

Из записи можно скопировать нужный раздел, выгрузить TXT, Markdown или WebVTT, подготовить черновик письма или создать зашифрованную ссылку на выбранные разделы. Личные заметки исключены по умолчанию. Ссылку можно защитить отдельным кодом и отозвать. Зашифрованная копия доступна до 30 дней, а отзыв может применяться на разных узлах с задержкой. История и календарь локальные, открытые по ссылке копии доступны в браузере без установки PeopleDo.

### Сборка и облачная конфигурация

`npm run desktop:package` упаковывает Electron из `/usr/lib/electron44` и кладёт архив в `desktop-build/`. Для другой установки Electron 44 есть переменная `PEOPLEDO_ELECTRON_DIR`. GitHub Actions собирает только архив Omarchy x86_64.

`npm run build` подготавливает Worker, включая маршруты `/summary`, `/shares/create`, `/shares/revoke` и просмотр заметки. При развёртывании Worker должен сохранить секрет `PROXYAPI_API_KEY` и привязку `SHARES`. Хранилище ссылок получает шифротекст, а ключ чтения передаётся во фрагменте ссылки или отдельным кодом.
