# Голосовые заметки

Локальная расшифровка речи с микрофона через faster-whisper. Результат сохраняется единым текстом в истории SQLite с поиском. При первом запуске потребуется интернет для загрузки модели.

```bash
uv run --no-project --python 3.11 --with-requirements requirements.txt python app.py
```

Открой http://localhost:8765 и разреши браузеру использовать микрофон.
