# Тестовый звонок PeopleDo

[Открыть демо на GitHub Pages](https://lubyek.github.io/voice-notes-local/). Нажми «Запустить тестовый звонок», чтобы услышать русскоязычного собеседника. В конце его реплики микрофон выключится автоматически. Для своей речи используй кнопки «Включить микрофон» и «Выключить микрофон».

Во время речи браузер посылает короткие WAV-фрагменты в Grok STT 2.0 через Cloudflare Worker, по возможности отправляя их по паузам. ProxyAPI принимает аудио отдельными файлами. Как только микрофон выключается и Grok заканчивает последний фрагмент, весь текст идёт одним запросом в DeepSeek V4.1 Flash. Очищенная версия появляется по мере генерации в отдельной панели. История обеих версий хранится в браузере.

## Публикация

GitHub Pages публикует папку `/docs` из ветки `main`. Секрет `PROXYAPI_API_KEY` хранится в Cloudflare Worker. Для сборки обработчика используй `npm ci`, `npm run build` и `npx cf deploy --prebuilt --dry-run`. Для публикации войди через `npx cf auth login` и выполни `npx cf deploy --prebuilt --secrets-file <закрытый-файл>`. В `docs/service-config.js` укажи адрес Worker без пути. Worker обслуживает `/transcribe` и `/cleanup` и ограничивает запросы по IP и точке присутствия.

## Локальный Python-сервер

```bash
read -r -s -p 'Ключ ProxyAPI: ' PROXYAPI_API_KEY
export PROXYAPI_API_KEY
python app.py
```

На http://localhost:8765 доступен режим записи через Python с финальной обработкой после остановки. История этого режима хранится в SQLite.

## Настольная личная расшифровка

Настольная версия PeopleDo запускается в фоне и остаётся в трее. При обнаружении активного микрофона в другом приложении PeopleDo показывает компактный запрос на расшифровку. В Linux он отслеживает активные входные потоки PipeWire, включая захват микрофона браузером. PeopleDo снова предлагает запись при каждом новом включении микрофона. Во время записи PeopleDo предлагает паузу после выключения микрофона. При повторном включении карточка предлагает продолжить запись, если она на паузе. На Linux изменения кнопки микрофона в поддерживаемых вкладках Chromium обнаруживаются локально через AT-SPI, когда в браузере включён системный интерфейс доступности. Его можно пропустить или нажать «Транскрибировать». Запись также можно начать вручную из окна, которое открывается через значок PeopleDo в строке меню или системном трее.

После подтверждения PeopleDo захватывает собственный вход с микрофона. На паузе приложение освобождает микрофон. «Возобновить» продолжает ту же расшифровку, а «Завершить» обрабатывает остаток речи и запускает очистку текста. Кнопка выключения микрофона внутри стороннего созвона может оставлять устройство открытым, поэтому для управления записью используй кнопки PeopleDo.

Аудиофрагменты обрабатывает Grok STT 2.0 через настроенный Worker. DeepSeek очищает текст после завершения. Последняя расшифровка доступна в текущем окне настольного приложения. В MVP один сеанс включает до 15 минут записанного звука. Аудиодорожка собеседников с системного выхода в запись не входит.

### Сборки для тестирования

GitHub Actions собирает архивы для macOS 14.2+ (Apple Silicon и Intel) и Windows x64. На macOS распакуй архив и открой `PeopleDo Transcription.app`. Сборка для тестирования имеет локальную подпись и не проходит нотарификацию Apple. На Windows распакуй весь архив и запусти `PeopleDo Transcription.exe` из распакованной папки.

Для самостоятельной сборки на macOS установи Xcode Command Line Tools и Node.js 24, затем выполни `npm run desktop:package`. На Windows запусти ту же команду из x64 Native Tools Command Prompt for Visual Studio с установленным Windows SDK. Готовый архив появится в `desktop-build`.
