# Голосовые заметки

Локальная расшифровка речи с микрофона через faster-whisper. Результат сохраняется единым текстом в истории SQLite с поиском. При первом запуске потребуется интернет для загрузки модели.

```bash
uv run --no-project --python 3.11 --with-requirements requirements.txt python app.py
```

Открой http://localhost:8765 и разреши браузеру использовать микрофон.

## GitHub Pages

[Открыть браузерную версию](https://lubyek.github.io/voice-notes-local/). Выбери язык записи в списке. По умолчанию выбран русский. Браузерная версия расшифровывает запись после остановки. При первой расшифровке браузер загружает многоязычную модель Whisper Tiny и файлы для запуска модели. Аудио обрабатывается на устройстве, история хранится в браузере.

Для публикации выбери в **Settings → Pages** источник **Deploy from a branch**, ветку **main** и папку **/docs**. Для локального просмотра браузерной версии запусти `python -m http.server 8766 --directory docs` и открой http://localhost:8766.
